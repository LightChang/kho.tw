電工配線及可程式控制PLC基礎(桃園) 第3期 招生中

勞動力發展署桃竹苗分署　桃園市楊梅區

緣由：一、 增強就業職能：因應產業需求，培訓電機自動控制及配線相關專業技術人才，提升職場競爭力。 二、 因應職場變遷：面對社會經濟結構轉變及科技之發展培訓多元就業技能。 三、 滿足個人職業生涯規劃發展。 訓練目標：一、熟悉電工配線實務、可程式控制應用、人機控制介面設計及線路配線施工、用電設備檢驗及電路系統故障排除能力，達日後進入電機設備迴路及自動化控制迴路領域職場之基礎能力。 二、以電機設備組立、維修與操作為著眼點，熟悉電機設備迴路及自動化控制迴路、用電設備施工、檢驗等施工應用，符合工業配線配線丙級、用電設備檢驗丙級技術士技能標準，以達職場產業需求順利就業為目標。 三、本班課程輔導工業配線丙級技術士、用電設備檢驗丙級技術士證照內容。 就業展望：1.擔任自動控制工作，從事各產業自動化低壓自動控制相關工程及工廠製程等工作，諸如設備之機構組立、電控配線、PLC程式設備、試車等均是。 2.適合從事廠務維修、駐點保養、設備維修、水電施工等工作。適合自行創業、承接簡易施工案件。 3.電機工程師 、電機工程技術員、電子工程師、電子工程技術員等。 (1)共同科目(28小時)：新生報到、開訓典禮、結訓典禮、勞動權益法規、就業市場趨勢分析及求職技巧、性別平等、資訊及通訊科技(ICT)概念、資訊及通訊科技(ICT)平台應用、資訊及通訊科技(ICT)實際案例解析、淨零碳排 (2)基本電學常識(32小時)：1. 電之基本觀念。 2. 直流迴路分析。 3. 磁之基本概念介紹。 4. 交流基本概念。 (3)控制電路概論(32小時)：1. 自動化概論。 2. 電工法規應用。 3. 傳統控制電路分析。 4. 數位電路、邏輯(閘)電路介紹。 5. 工廠電路負載計算。 (4)可程式控制概論(16小時)：1. 市場常用機種硬體，構成及輸出入規格介紹。 2. 各機種擴充元件、各種元件功能及比較。 3. 可程式控制器常用機種指令語法介紹及比較。 4. 程式書寫器的使用、編輯軟體操作說明。 5. 市場可程式控制器應用介紹。 (5)電工學(32小時)：1. 常用電工基本公式總整理。 2. 交、直流電動機、發電機分類、原理、接線方式與維護。 3. 變壓器原理、構造、分類、接線方式與維護。 4. 三相、單相交流感應馬達原理、構造、分類、速度控制法、判別與維護。 5. 低壓電動機、電熱及其他工程。 (6)電力系統概論(24小時)：1. 用電安全。 2. 電力供給與需求。 3. 發電系統、輸電系統、配電系統、與電力市場簡介。 4. 高低壓供電系統介紹。 5. 低壓接戶線、進屋線及電表工程。 6. 電工法規應用。 (7)PLC可程式控制實習(136小時)：1. 編輯軟體操作。 2. 基本指令操作及應用實習。 3. 應用指令實習（資料、傳送、比較應用）。 4. SFC步進階梯流程應用實習。 5. 外部裝置I/O應用實習。 6. 串列通訊硬體架構及通訊協定。 7. RS232、RS422、RS485、Modbus通訊實習。 (8)人機介面控制實習(32小時)：1. 人機介面之發展應用 2. 人機介面及圖形編輯軟體操作 (9)用電設備檢驗實習(64小時)：1. 供電系統介紹與電工法規應用。 2. 用電設備檢測工具與儀表認識。 3. 用電設備量測電錶組裝實習。 4. 用電設備施工、檢驗綜合實習。 (10)綜合實習(148小時)：1. 丙級工業配線裝置配線1~7題目綜合實習。 2. 丙級工業配線故障檢修1~7題目綜合實習。 (11)控制電路實習(96小時)：1. 工業配線控制元件介紹。 2. 電動機啟動停止基本控制電路實習。 3. 寸動、多處控制電動機啟動停止實習。 4. 計時控制電路實習 5. 電動機正逆轉控制電路實習。 6. 單相感應電動機主線路實習。 7. 三相感應電動機主線路實習。 8. 單相、三相感應電動機控制綜合實習。 9. 比壓器、比流器應用實習。
