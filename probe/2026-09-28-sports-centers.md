起因：Google 自動完成的實際問法「三重／土城／新店／鳳山 運動中心 游泳課」站上接不到
（`docs/GROWTH.md` §1.3）。本文逐館查「課表在哪、能不能結構化取得」，體例接
`probe/2026-09-11-sources.md` 與 `probe/2026-09-13-libraries.md`。場館與營運商對照取自
全國運動場館資訊（`sports-venues`）與新北市體育局國民運動中心頁，再到各館官網確認現況。

## 0. 結論

1. **三重、板橋、樹林、鳳山其實早就接了，只是游泳課一門都沒抓到。** `xuanen-centers`
   用中山站的 10 個類別代碼掃每一站，但**軒恩的類別代碼是各站自編的**：中山的 14 是
   「泳訓團體」，三重的泳池課是 51／52／53／88。結果三重只抓到 31 門、鳳山 192 門、
   35 站合計 3,664 門。改成每站先讀自己的類別清單（課表頁 `rbn_2` radio）再逐類掃，
   加上新找到的 3 站共 38 站變成 **10,414 門**，課名或類別帶「泳／游／水中」的課從 342 門變成 1,702 門。
   這是本輪收益最大的一項，而且不是新來源。
2. **土城不在救國團了。** 全國運動場館資訊的官網欄還寫 `tccsc.cyc.org.tw`，那個網域現在是
   救國團各館的入口頁；土城改由遠東經營，官網 `tcsports.com.tw`，報名系統是
   軒恩 `fe.xuanen.com.tw/fe03.aspx`。同一台主機的 `fe02` 是竹北國民運動中心。
3. **新店的課表只在「長佳智慧運動中心」Web App 裡**（`changjia.sporetrofit.com`），官網只放圖片簡章。
   App 的課程清單是伺服器端 HTML、免登入，有報名人數與名額；課程詳情 API 會檢查請求來源，
   依 CONTRACT §2 不繞過，所以**這支沒有起訖日**。新接 `changjia-centers`（新店＋桃園蘆竹）。
4. **三峽、鶯歌是全越運動（teamxports），有公開的 Web API**，一支接 8 館（含臺北信義、臺中豐原），
   欄位最完整：起訖日、星期時段、報名起訖、剩餘名額、名額上下限。新接 `teamxports-centers`。
   三峽、鶯歌目前的期課沒有游泳類別（泳訓不在這套系統上）。
5. **淡水、泰山在軒恩早就有站，只是沒有名字。** `wd31`、`wd32`、`wd33` 用報名須知頁的服務電話
   對到淡水國民運動中心、泰山國民運動中心、泰山體育館（查證見 `overrides/xuanen-sites.json` 的 `_probe2`）。
6. **接不到的**：新莊（頂尖，課表是 Google Drive 上的 PDF）、中和（官網 Wix，課表是 PDF＋App）、
   蘆洲（展昭，課表是圖片）、五股（展昭，報名走 17fit，等待頁擋，09-11 已記錄不接）。
   深坑、萬里查不到國民運動中心。本專案沒有 PDF／圖片解析的管線，四館都先不接。

## 3. 三個平台的取法

### 3.1 軒恩（xuanen）：類別代碼每站不同

- 課表頁 `GET <站>.aspx?Module=class_booking&files=class_info` 不帶 `B` 時只回第一類，
  頁面上的 `rbn_2` radio 就是該站的類別清單（代碼＋名稱）。每站 1–23 類，38 站合計 475 類。
- `A` 參數是「方案」（`rbn_1`，全部／115-4 球類有氧團體課…），維持帶「全部」。
- 回應 1 秒內，成本在每次請求間隔 2 秒。38 站共約 510 次請求（類別清單＋各類別），
  改成**同主機串行、不同主機併行**（7 台主機），實測 21 分鐘（最慢的是 bwd 那台，17 站）。
- 仍找不到名稱的站：`wd22`（電話 (02)2708-6000 查不到）、`wd28`、`wd34`、`wd37`（報名須知頁沒有電話）。

### 3.2 全越運動（teamxports）

- 前端是 Vue SPA，API 在 `https://WEBAPI.Teamxports.com`，路徑取自前端 js 的 `src/api/*.js`。
- `site-list`（館名、地址）→ `filter-pckg-multiple`（該館期課類別）→ POST `multiple-course-list`
  （JSON，`memberId` 要給數字 0，給 `null` 會回 400「Incorrect Content-Type」）。
- `avaliableCount`（原文拼法）＝`capacityMax − signedUpCount`，578 筆全部相符。
- 狀態碼的意思取自前端 `getButtonLabel()`：1 報名時間未到、2 報名時間已過、3 課程已開始、4 限原班續報。
- **教師姓名前端刻意遮成「林●皓」**，API 雖然給全名，normalize 不收。
- `filter-pckg-single`（單堂課）各館都是空的。`site-list-brief` 的 `siteId` 給 0 會回「查無資料」。

### 3.3 長佳智慧運動中心（sporetrofit）

- 首頁的隱藏表單列出各館 `LID`（新店 `XDSC`、蘆竹 `LZSC`）。
- `POST /Location/CourseList/ajax/createTable/`：`LID`、`LIDName`（不帶會回空）、`CategoryID`、
  `count=500` 一次取完；不帶 `count` 時一頁 8 門，靠 `index` 往下捲。
- 同一支帶 `redirectFromFilter=true&weekDay=0–6&CategoryID=` 是前端的「依星期篩選」，
  用來反查星期（0＝日）。新店七天合計 92 門，與逐類別合計相同。
- 清單只列**還能報名或插班**的課：新店週二到週四的課 9 月初開課、已過第四堂，清單裡一門都沒有。
- 「報名狀況: (a/b)」的 a 是已報名：詳情頁的寫法是 `報名${CurrentEnterNumber}/${EnterNumber}人`；
  新店 92 門裡 a＝b 的 61 門、a＝0 的 0 門，若 a 是剩餘名額就等於三分之二的課沒人報名卻沒有一門額滿。
- 詳情 API `/api/getRequestData.php` 回「Invalid request origin」，不繞過。
- robots.txt 回 403。
